## 📱 Mobile App for Students *(new)*

The Civic Action Project is now available as a mobile app for iPhone and Android. Students can install it directly from the browser — no app store, no account, no ads — and use it to:

- Browse all 39 CAP assignments and review their rubrics on the go
- Capture photos or video reflections directly from inside the app
- Hand off submissions to Canvas Student through their phone's native share sheet
- Track progress toward 100 points with the multi-category requirement check

**Install page:** [`install-app.html`](install-app.html) — step-by-step instructions for both platforms, plus a QR code for direct install.

**Direct app link:** [`CAP_Mobile_App.html`](CAP_Mobile_App.html)

The app is a self-contained Progressive Web App (PWA). All assignment content, rubrics, and progress tracking live entirely on the student's device. No data is sent to any server — submissions go straight to Canvas through the phone's share sheet, keeping the system FERPA-compliant by architecture.
